The one dependency worth naming

Everything above is automated and free except candidate generation — turning "all Swedish energy & transport firms ≥50 staff" into names + domains + SNI codes. This run hand-verified that step, which is why the 10 are trustworthy and 50–100 needs a registry feed (allabolag / Bolagsverket / Roaring). The engine's Company shape is already built for it — wiring one in changes nothing downstream. This is the scaling boundary, stated plainly, not a hidden one.

And it's built to feed the stack. The same collectors run behind one POST /enrich call — a domain in, this whole signal bundle out as flat JSON — so it drops straight into Clay's enrichment waterfall and on into UpliftIQ's scoring. The signal isn't the moat; the signal wired into the systems that close the loop is.

Screening, not adjudication. The NIS2 verdict is a screening heuristic, not a legal determination. "No visible CISO" is a confidence signal to verify by hand before outreach, never a claim of absence.
