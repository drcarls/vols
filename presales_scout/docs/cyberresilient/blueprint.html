Architecture

Build four. Aim them many places. Run it all on your side.

The nine use cases aren't nine things to build. They're four core capabilities pointed at different targets, cadences, and audiences — an observed-signal input (Observe, Reconcile) feeding UpliftIQ's decision optimization (Cluster+Benchmark, Recommend+Optimize), which refines over time. The whole thing runs inside your environment, so customer data never leaves.

A · Build four, aim many

Four capabilities → nine use cases

Each use case is one of four capabilities aimed at a new target, cadence, or audience. Two capabilities are moat-grade — they run on the clustered cross-customer corpus.

B · Runs where the data lives

Embedded in your environment — data never leaves

UpliftIQ deploys inside your tenant, not as a service you ship data to. Only two things cross the boundary: public signals in, and derived, anonymized results out. The customer corpus stays put.

Four capabilities. Nine plays. One sovereign boundary — the data never leaves, and the intelligence runs where it lives.

What this changes commercially. Embedded/in-premise makes UpliftIQ the brain inside the platform, not a data-processing SaaS — a stickier, OEM-style relationship, and the only shape that keeps CyberResilient's sovereignty promise intact while enabling the cross-customer moat. One requirement, not a caveat: the benchmark and sector plays need contractual consent plus a minimum cluster size (k-anonymity), so no output re-identifies a customer. On-prem removes egress risk; this removes re-identification risk. Both are part of the sovereignty story.
