The flow

One pipeline, from raw registry to a self-sharpening lead engine.

The engine is the part I built: it turns a registry of Swedish firms into ranked, context-mapped prospects using only passive public signals. The value isn't the scraper — it's that this signal plugs into your GTM stack and gets sharper every time you close a deal.

What moves through it

Five stages, clean seams between them

STAGE 0
Harvest
Registry → every energy/transport firm in scope, by SNI code + size.
STAGE 1–4
Enrich
Passive signals per firm: NIS2, email, CISO + hiring, attack surface, suppliers.
STAGE 5
Context-map
Each finding → its NIS2 measure, ISO control, severity, and CD service.
STAGE 6
Integrate
One JSON call feeds Clay's waterfall and UpliftIQ's scoring.
STAGE 7
Close the loop
Assessment outcomes retrain the fit model — sharper every deal.
🔁

Why it compounds. Anyone can check a DMARC record. What can't be copied is this signal wired into your conversion and assessment data — so the prediction improves with every engagement, on a dataset that lives on no competitor's servers. Each seam between stages is clean JSON/CSV, so no single box is the lock-in; the loop closing is.

Built and running today. The engine (Stages 0–5) is code you can run now — presales harvest → discover, plus a POST /enrich endpoint that returns the whole bundle as JSON. Stages 6–7 are the integration and the feedback capture: they need a registry credential and one field in your CRM, both yours to switch on. Every engine signal is passive and public — no scanning, no probing, nothing behind a login. Full provenance in the Sources & Method companion.
